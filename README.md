## Sobre mim

Olá! Eu sou **Leonardo Barbosa**, estudante de **Desenvolvimento de Sistemas no SENAI**.

Uso o GitHub para documentar minha evolução, organizar meus estudos e transformar conceitos de programação em projetos práticos. Tenho interesse em desenvolvimento web, criação de interfaces, lógica de programação, bancos de dados e construção de sistemas bem estruturados.

Meu objetivo é evoluir continuamente como desenvolvedor, fortalecendo minha base técnica e criando aplicações cada vez mais completas, organizadas e úteis.
